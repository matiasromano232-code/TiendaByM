# Tienda ByM - E-Commerce 

## 📂 Estructura del Proyecto

Tienda ByM/
│
├── assets/                 # Recursos multimedia y estáticos
│   ├── img/                # Imágenes de productos, banners y logos
│   ├── fonts/              # Fuentes tipográficas personalizadas
│   └── icons/              # Iconografía del sitio (SVG, PNG)
│
├── css/                    # Hojas de estilo
│   ├── style.css           # Archivo principal de estilos
│   └── variables.css       # Variables globales (colores principales, fuentes)
│
├── pages/                  # Vistas secundarias del sitio
│   ├── catalogo.html       # Catálogo de productos electrónicos
│   ├── sobre-nosotros.html # Información sobre la marca
│   └── contacto.html       # Formulario de atención al cliente
│
└── index.html              # Página de inicio (Landing Page)
